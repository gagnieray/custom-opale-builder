# Opale Redmine Theme Customized

This customized version of [Opale Redmine Theme](https://github.com/gagnieray/opale):

- restores the brand primary color used in [PurpleMine2](https://github.com/mrliptontea/PurpleMine2)
- adds a favicon
- adds a logo
